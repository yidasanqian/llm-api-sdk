# Security Policy

## Supported versions

Security fixes are provided for the latest released version. Development snapshots and older releases are not supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting from the repository **Security** tab and include:

- the affected SDK version;
- a minimal reproduction or proof of concept;
- the expected impact;
- any suggested mitigation.

Do not include live API keys, access tokens, customer payloads or private endpoints. The maintainer will coordinate validation and disclosure through the private advisory.
